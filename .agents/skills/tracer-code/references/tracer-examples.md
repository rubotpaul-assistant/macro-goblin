# Goblin tracer examples

## Iron Goblin

Start from a fixture with one scheduled workout already active. Read its prescription IDs, record one three-set exercise with final-set RIR, drop the response after commit, and repeat the same authorized command with its original key. The performed-history read should identify the same active workout and exactly three sets. Compare the canonical outcome with the existing CLI.

## Macro Goblin

Use an owner-bound catalog fixture and log one known food by canonical ID. Repeat the authorized command with its original key after changing the reusable catalog profile. The replay should return the original entry reference and values. Read history to confirm one immutable snapshot retains the original portion, provenance, and fixed-point nutrient values.
